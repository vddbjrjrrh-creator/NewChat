О сервисе

Кто делает Newchat
Newchat — независимый мессенджер, его пишет небольшая команда энтузиастов. Мы не принадлежим корпорации и не продаём данные пользователей. Вопросы и жалобы — через плашку DEV рядом с именем разработчика.
Где хранятся данные
Сервер приложения — Render (США), тариф бесплатный.
База данных — Neon PostgreSQL, шифруется при хранении.
Само приложение — GitHub Pages.
Звонки — напрямую между собеседниками (WebRTC), сервер видит только факт вызова. Когда прямое соединение не проходит, звук идёт через ретранслятор без записи.
Серверы арендованы на тарифах для разработчиков. Сервис некоммерческий, денег с пользователей мы не берём.
Что мы храним
Переписку, профиль и юзернеймы — чтобы мессенджер работал.
Телефон или почту — только как способ входа.
Видео, кружки и файлы удаляются автоматически через 7 дней.
Слепки переписки сохраняются при жалобах «Скам» и «Докс» — чтобы мошенники отвечали по закону.
Честные ограничения
Сервер на бесплатном тарифе засыпает без нагрузки — первый вход после паузы может занять до минуты.
Переписка шифруется при передаче и хранении, но сквозного шифрования пока нет: технически администратор может прочитать сообщения. Для тайн государственной важности мы не подходим, и мы об этом говорим прямо.

Пожаловаться

Вся переписка — включая сообщения, которые собеседник удалил, — будет автоматически передана в полицию.

Ложные жалобы снижают батарейку доверия. Система проверяет скорость и связи жалующихся аккаунтов.

Жалоба: скам

Соберём полный протокол переписки с «» — со всеми удалёнными сообщениями и данными аккаунта. Документ откроется прямо здесь, его можно сохранить в PDF.

После подачи: 2 суток без новых жалоб и без биржи. Так протокол не используют ради чтения удалённых сообщений.

Готовим протокол

○ Сбор переписки и удалённых сообщений
○ Данные собеседника и время регистрации
○ Формирование документа для заявления
